Приложение Wose

Wose работает локально и не требует учётной записи. В этой версии нет аналитики, рекламных идентификаторов и отправки статистики разработчику.

  • Настройки, задачи, привычки, записи воды, время фокуса и пути к файлам полки сохраняются в %LOCALAPPDATA%/Wose/settings.json. Полка ссылается на файлы в их исходных папках.
  • История текстового буфера выключена при первом запуске. После включения скопированные тексты хранятся в памяти до завершения работы Wose.
  • Для статистики токенов Wose читает локальные журналы Codex и Claude Code. Он не подключается к кабинетам провайдеров и не запрашивает их пароли.
  • Информация о треке, громкости, питании, раскладке, сети и устройствах получается из интерфейсов Windows. Доступ к системным уведомлениям зависит от возможностей Windows и разрешения пользователя.
  • Полученные уведомления используются для показа и перехода к источнику. История уведомлений хранится в памяти, а не отправляется на сервер Wose.

Обновления и лицензия Pro

Автоматическая проверка обновлений включена по умолчанию и выполняется не чаще раза в день. Её можно выключить в настройках; ручная проверка остаётся доступной. Wose запрашивает подписанное описание выпуска на GitHub Pages, а по нажатию скачивает EXE из GitHub Releases. Эти сервисы получают обычные технические сведения соединения, включая IP-адрес. Настройки, списки, сообщения, лицензия и другие локальные данные в запрос не включаются. Установка выполняется только по нажатию; служебные файлы проверки и результат установки остаются в %LOCALAPPDATA%/Wose/Updates.

Pro активируется импортом подписанного файла лицензии без сетевой проверки. Лицензия и профили облика хранятся локально в папке Wose. Профили содержат выбранное оформление и поведение персонажа, без файлов, задач и разрешений. В приложении нет платёжного сервиса.

Capture: снимки экрана

Capture создаёт снимок экрана, окна или выбранной области, сохраняет PNG на диск, копирует изображение в буфер обмена Windows и автоматически добавляет файл на полку. Снимки не отправляются на сервер Wose. Файлы остаются в папке сохранения, пока ты не удалишь их самостоятельно; другие приложения с доступом к буферу могут прочитать скопированное изображение.

Подключение ИИ-инструментов

Подключение включается кнопкой «Подключить» во вкладке «Агенты». Подключённые инструменты передают локальные hook-события о состоянии работы: например, агент работает, ждёт действия или завершил ответ. Wose сохраняет метаданные событий, а не тексты запросов. История ограничена семью днями, 256 событиями и 64 сессиями. Канал hook-событий работает локально и не отправляет запросы или эту историю во внешние сервисы.

Для Cursor Wose получает только метаданные состояния агента.

Статистика токенов Codex и Claude Code читается отдельно из локальных журналов. Она не означает доступ к балансу API или кабинету провайдера. Отключение подключения прекращает приём новых событий.

Поиск текста песни

Локальные файлы LRC обрабатываются на компьютере. При поиске в LRCLIB название трека и исполнитель передаются этому сервису. Автоматический поиск по умолчанию выключен; его можно включить в настройках. При сетевом запросе сервис также получает обычные технические сведения соединения, в том числе IP-адрес. Настройки LRCLIB находятся за пределами Wose.

Расширение Chrome и Edge

Расширение необязательно. Передача уведомлений в Wose изначально выключена. При обычном запуске Wose подготавливает локальное подключение Chrome для текущего пользователя Windows. Кнопка «Подключить Wose» в расширении включает передачу из вкладок в приложении и расширении после подтверждения связи. Самому сайту по-прежнему требуется разрешение браузера на уведомления.

  • На обычных страницах HTTP и HTTPS расширение наблюдает стандартные вызовы new Notification. При включённой передаче оно отправляет локальному приложению идентификатор уведомления, домен сайта, заголовок и текст. Полный адрес страницы не передаётся.
  • Идентификаторы вкладки, окна и документа временно хранятся внутри браузера, чтобы нажатие на уведомление вернуло к отправившей его вкладке. Эти сведения не отправляются на внешний сервер.
  • Если Wose не подтвердил получение при отправке, уведомление показывает браузер. Фоновые push-уведомления, уведомления с тегами и requireInteraction остаются браузерными.
  • Расширение не собирает историю посещений, пароли или содержимое страниц и не обращается к удалённым сервисам. В хранилище браузера сохраняется только положение переключателя передачи.
  • Ожидающие сообщения и записи для переходов хранятся в памяти. Они очищаются при отключении передачи и закрытии соответствующей вкладки или завершении рабочего процесса расширения. Режим инкогнито не поддерживается.

Уведомления могут содержать личные сообщения. Включай прямую передачу, только если хочешь видеть их текст в панели Wose. Отключение переключателя прекращает дальнейшую передачу.

Этот сайт

На сайте нет аналитики, рекламы, форм регистрации и сторонних шрифтов. Видео показывают интерфейс с примером данных. Выбор функции и состояние воспроизведения остаются на странице. При переходе по внешним ссылкам действуют правила соответствующего сайта. Хостинг может обрабатывать обычные журналы запросов в соответствии со своей политикой.

Как удалить данные

Выключи передачу в расширении и удали его через настройки браузера. В Wose выключи автозапуск, затем закрой программу через трей. Для удаления локальных настроек удали папку %LOCALAPPDATA%/Wose. Исходные файлы, которые были на полке, от этого не удаляются. PNG-снимки Capture в других папках нужно удалить отдельно; очистить буфер обмена можно средствами Windows. Удаление регистрации локального моста описано в инструкции расширения.

Изменения политики

Если обработка данных изменится, эта страница будет обновлена вместе с соответствующей версией.
