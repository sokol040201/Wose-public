Установка расширения Wose

Расширение передаёт уведомления открытых сайтов в запущенное приложение Wose. Для установки нужны архив расширения и Wose для Windows.

Скачать расширение для Chrome

  1. Распакуйте архив

    Выберите постоянную папку. В ней находятся папка extension с manifest.json, скрипты подключения и README. Chrome будет использовать эти файлы после установки.

  2. Загрузите расширение в Chrome

    Введите chrome://extensions в адресную строку. Включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку extension с файлом manifest.json.

  3. Подключите Chrome к Wose

    Запустите REGISTER-CHROME.cmd из архива. Если Wose.exe не найден рядом, выберите файл приложения в открывшемся окне.

    Настройка регистрирует подключение для текущего пользователя Windows. Права администратора не нужны. После регистрации перезапустите Wose.

    Ручная регистрация через PowerShell

    Откройте терминал в папке со скриптом register.ps1 и выполните команду с настоящим путём к Wose.exe:

    powershell -NoProfile -ExecutionPolicy RemoteSigned -File .\register.ps1 -Browser Chrome -WoseExe "C:/Wose/wose.exe"

    Если Windows блокирует скачанный скрипт, сначала проверьте его содержимое. Разрешение запуска файла можно изменить в его свойствах. Подробности есть в FULL-README.md внутри архива.

  4. Включите передачу уведомлений

    В настройках Wose откройте «Уведомления → Приложения» и включите «Напрямую из вкладок». Затем откройте Wose на панели расширений Chrome, включите передачу и нажмите «Проверить подключение».

    Разрешите уведомления нужному сайту средствами Chrome. Обновите вкладки, открытые до установки расширения.

Какие уведомления передаются

Поддерживаются обычные вызовы new Notification из открытых HTTP- и HTTPS-страниц с разрешением на уведомления. Клик в Wose возвращает к исходной вкладке, если она ещё доступна.

Уведомления service worker, фоновые push и сообщения с особыми условиями показа, включая tag, requireInteraction, renotify и дополнительные действия, остаются в браузере. Если Wose не принимает сообщение, его показывает Chrome.

Перенос и удаление

После переноса Wose.exe повторите регистрацию с новым путём. Чтобы отключить передачу, используйте переключатель расширения. Для полного удаления сначала удалите расширение в Chrome, затем отмените регистрацию:

powershell -NoProfile -ExecutionPolicy RemoteSigned -File .\register.ps1 -Browser Chrome -Uninstall

Обработка уведомлений описана в политике приватности.
