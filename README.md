# Wose public distribution

Website: https://sokol040201.github.io/Wose-public/

This repository contains the compiled website, component licenses and public
release packages. Application source and private documents are kept separately.
Download the Windows application and Chrome bundle from Releases (v0.8.2 stable).
Chrome installation instructions are linked from the website.

The counter reports GitHub release asset downloads for Windows application ZIPs
across published releases, including previews. It does not count unique people or
installations. Pages refreshes the validated statistics on release publication,
site pushes, manual runs and every six hours. A failed refresh stops deployment.
